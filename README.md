# QuizGame

Викторина: вопрос и 4 варианта ответа, проверка выбора и итоговая статистика по правильным и неправильным ответам.

Проект сделан в рамках обучения TDD-разработке: каждая фича начиналась с UI-теста, потом шла реализация.

## Что показывает проект

- TDD: сценарные UI-тесты (Espresso) пишутся до кода, у каждого сценария есть номер тест-кейса
- Page Object для двух экранов: игра и итоговая статистика
- Проверка пересоздания Activity на каждом шаге сценария
- Обработка смерти процесса и поворота экрана
- Сохранение прогресса и статистики между запусками (SharedPreferences)
- Кастомные view (кнопки вариантов, статистика) с сохранением состояния через SavedState
- Unit-тесты для GameViewModel

## Стек

Kotlin, XML/View, ViewBinding, JUnit, Espresso

## Как запустить тесты

Unit-тесты:

    ./gradlew test

UI-тесты (нужен запущенный эмулятор или подключенное устройство):

    ./gradlew connectedAndroidTest
